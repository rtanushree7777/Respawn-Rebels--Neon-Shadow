# Respawn-Rebels--Neon-Shadow
NEON SHADOW: Chromatic Chronicles is a 2D sci-fi stealth-action platformer featuring futuristic ninjas, intelligent enemies, day/night environments, character customization, unlockable abilities, and challenging missions. Built using HTML5, CSS3, and JavaScript for an immersive, interactive gaming experience.

## Play online

**[Play NEON SHADOW in your browser](https://rtanushree7777.github.io/Respawn-Rebels--Neon-Shadow/)** — keyboard, mouse and touch supported.

To run it locally, open `index.html` in a current browser (Chrome, Edge, Firefox or Safari).
